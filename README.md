# Prompt Injection Playground

Prompt Injection Playground — learn LLM security hands-on with safe, sandboxed attack demos. Understand jailbreaks, indirect injection and data exfiltration patterns before attackers do. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/prompt-injection-playground/

## About
Prompt Injection Playground is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **Security & LLM Tools**.

## Features
- Guided labs: direct injection, indirect injection, jailbreaks
- Scored challenges with explanations of why attacks work
- Defense playground: test mitigations against live attacks
- OWASP LLM Top 10 coverage map
